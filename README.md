## Reflection Questions

### 1. What challenges did you face when refactoring your code to use Bootstrap?

The hardest part was figuring out which Bootstrap classes could replace the CSS I already wrote. Once I got used to the Bootstrap classes, it became easier to work with.

### 2. How did using Bootstrap utility classes and components simplify your styling process?

Bootstrap made things easier because a lot of the styling was already built in. I didn't have to write as much CSS, and I could use Bootstrap classes to handle spacing, alignment, and the card layout.

### 3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?

I would use custom CSS if I wanted a more unique design or if I needed more control over how the website looks. Sometimes custom CSS gives you more flexibility than Bootstrap.
